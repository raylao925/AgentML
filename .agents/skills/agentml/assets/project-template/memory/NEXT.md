# NEXT — Live Queue (what to run next)

## Purpose
The single "what now" answer for the next session. Ranked by **expected Δ per unit cost**, capped
at 5 live entries. It is the agent's working memory across sessions — write it down rather than
expecting the reader to re-derive it.

## How to Use
- **Read first** at session start (`01_lifecycle.md` Step 0.5). Do not plan until you have read it.
- **Rewrite every round** (`01_lifecycle.md` Step H / `program.md` Step E): re-rank, promote, drop.
- **Authoritative over `doc/06_experiment_log.md` §G.** §G is the archived mirror (one `G.x` block
  per round, appended for the record); this file is the live state. If they disagree, `NEXT.md`
  wins and §G is behind — refresh it.
- Protocol: `references/10_iteration_loop.md` §2 (five fields, EV/cost ranking, depth cap).
